# 2yearsvaleria ♡

Небольшая интерактивная открытка для Валерии к вашей второй годовщине.

## Как посмотреть сайт

Откройте файл `index.html` в браузере. Проект статический: без сборки, npm и сторонних библиотек.

## Как опубликовать через GitHub Pages

1. Откройте репозиторий **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. В качестве ветки выберите `main`, а папки — `/(root)`.
4. Нажмите **Save**. После публикации GitHub покажет адрес сайта в этом же разделе.

## Как персонализировать открытку

Весь сайт находится в `index.html`. Найдите в нём текст письма, карточки «Ты для меня — это…» и секретное признание, чтобы добавить свои слова, общие шутки и ваши воспоминания. Если захочется добавить фотографии, их тоже можно встроить прямо в эту страницу.

Сайт адаптирован для телефона и компьютера, анимации учитывают настройку уменьшения движения в системе.
